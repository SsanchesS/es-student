Сконфигурировать сборку
cmake -G "Unix Makefiles" ..

CMake генерирует сценарий сборки, по которому Make на следующем шаге выполнит сборку проекта.
В выводе не должно быть ошибок, а в конце — сообщения об успешной генерации

Собрать прошивку
make

Make запускает компилятор и компоновщик для всех файлов проекта, подставляя нужные флаги и следя за зависимостями. 
Здесь происходят препроцессинг, компиляция, компоновка двоичного файла и преобразование его в формат uf2. Make работает по сценарию, который сгенерировал ему CMake.

Перевести плату в режим загрузчика

Записать прошивку

Скопируйте файл 112_blink.uf2 из директории build на плату
мышью или командой из терминала. Команды выполняются из директории build, в которой вы собирали прошивку

Чем отличаются .bin и .uf2
.bin — двоичный файл прошивки, в точности то, что должно оказаться во флеш-памяти микроконтроллера. Его записывают программатором напрямую.
.uf2 — формат для упрощённой записи через USB, обёртка вокруг той же прошивки. Она позволяет просто скопировать файл на плату, у которой есть соответствующий загрузчик. Результат в обоих случаях одинаковый.
